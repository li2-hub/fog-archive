## 四、录屏脚本

**录屏 1 主线通关（90s）**
1. 入口页 → 开始调查（0:00）
2. 图书馆门厅 → 翻闭馆记录 → B1 门禁 → 书库 → 监控回放（0:10）
3. 打开线索板，组合门禁+监控 → 推理成功动画（0:40）
4. 实验楼走廊对话 → 403 残页 → 线索板组合借阅卡+残页（0:55）
5. 看台目击者 → 储物柜 → 教务处最终判断 → A 结局（1:10）

**录屏 2 存档恢复（60s）**
1. 走到中途（有 3 条线索、1 条推论）→ 从最近任务划掉 App
2. 冷启动 → 入口页显示存档摘要 → 继续 → 回到原节点、HUD 数值一致
3. 继续走到结局，证明状态连续

**录屏 3 分支与异常（60s）**
1. 新档只拿 3 条线索直接进最终判断 → B 结局
2. 结局页展示"未达成项"清单
3. 演示损坏存档提示（可剪入或口述）
